# Implementation Notes

This bounded implementation is deliberately useful without a frozen central PDK:

- deterministic Decimal/time/hash primitives;
- conservative relationship/equivalence validation;
- quote/FX normalization and evidence linkage;
- complete-cost gating and capacity/depth logic;
- signal and opportunity candidates with typed feature provenance;
- strict-vs-near classification and stale/eligibility blockers;
- Level-2 multi-leg paper-plan translation plus a non-authoritative deterministic preview simulator;
- outcome candidate evaluation;
- provider admission guard and deterministic fixture provider;
- plugin repository protocols, in-memory implementation, host-applied namespaced migration;
- typed configuration and deterministic version hashes;
- resumable/idempotent batch detection checkpoint runner;
- real comparison-matrix read projection for dashboard integration;
- bounded evidence-linked learning recommendations that never auto-apply;
- declarative UI/CLI/operation/permission descriptors;
- compatibility diagnostics and no-live-execution boundary tests.

Not claimed in this pass: live provider qualification, exact core PDK adapter, direct cross-cylinder production reads, authoritative central paper-ledger mutation, or host persistence wiring. Those require the recorded `CENTRAL_HUB_INTEGRATION_REQUESTS` and must be implemented by the central workstream, not duplicated here.
